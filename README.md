## What This Is

I'm building interactive visualizations for every major ML algorithm. Each visualization lets you:

- Adjust parameters and see results in real-time
- Understand the math through visual intuition
- Prepare for ML interview questions

This repo is being deployed incrementally. **Linear Regression** is the first in the series.

## Run Locally

```bash
pip install -r requirements.txt
streamlit run apps/Linear\ regression/app.py
```

## What's Inside

### Linear Regression Visualization

- **Manual fitting** — Adjust slope/intercept to match the optimal line
- **Residuals visualized** — See errors as vertical lines
- **MSE scoreboard** — Compare your fit against OLS
- **OLS Assumptions** — Q-Q plots, homoscedasticity checks, VIF calculator
- **Interview questions** — Common ML interview questions with answers
